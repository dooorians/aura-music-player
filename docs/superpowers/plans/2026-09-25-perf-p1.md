# Aura — P1 performance fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the four P1 items of the 2026-09-25 performance audit without changing any behaviour or visual: fewer recompositions per playback tick, no per-frame allocation in the seek bar's wave, no rebuilt pager page list, no recomputed alphabet-index keys.

**Architecture:** Four independent, local edits in Jetpack Compose code. Two defer a high-frequency state read (playback position, 2 Hz) into the small composables that need it, by passing a `() -> Long` provider instead of a `Long`. Two add a `remember` around an allocation made on every recomposition or every frame. No public behaviour, layout or data model changes.

**Tech Stack:** Kotlin 2.2.10, Jetpack Compose (BOM 2026.02.01, Strong Skipping on), AGP 9.4, Hilt. Android app `com.ikko.aura`.

**Spec:** The P1 table of the performance audit delivered in the conversation on 2026-09-25 (items 1–4). Note that item 1 was overstated in the audit: with `val positionMs by …` the state is read where `positionMs` is used, so what recomposes twice a second is the `GradientScreenScaffold` content lambda of the player (its column of six blocks), not the whole `NowPlayingScreen` body. The fix is the same; the gain is smaller than first stated.

## Review Focus

1. Scrubbing the seek bar: while a finger drags, the bar and the time labels follow the finger (`dragFraction`), not the playback position; on release it seeks. Must be unchanged after Task 2.
2. Pausing playback: the wave flattens and stops, the lyric sweep stops at the current word, the time labels stop. The position provider must still drive `rememberLyricClock`'s `LaunchedEffect(positionMs, …)` keys (Tasks 2 and 3).
3. A new lyric line: the player's lyric bubble and the lyrics page still move to the new line when the position crosses its timestamp (Tasks 2 and 3).
4. Unknown or zero duration (a track still loading): the bar shows 0:00 and does not divide by zero (`safeDuration = durationMs.coerceAtLeast(1L)`), unchanged (Task 2).
5. Changing the library sort (Nom / Artiste / Date d'ajout) or rescanning: the alphabet index's letters and jumps follow the new order immediately; under "date d'ajout" there is no index at all (Task 5).

These are checked on the device in Task 6 — there is no unit or UI test infrastructure in this project, and adding it is out of the P1 scope.

### Task 2: Read the playback position only in the player's bar and lyric bubble

**Files:**
- Modify: `app/src/main/java/com/ikko/aura/ui/components/WavyProgressBar.kt` (parameters `positionMs`, `durationMs`, ~lines 69-88)
- Modify: `app/src/main/java/com/ikko/aura/ui/screens/nowplaying/NowPlayingScreen.kt` (call sites ~lines 383-410; `LyricCapsule` ~lines 468-476)

**Interfaces:**

- Produces: `WavyProgressBar(positionMs: () -> Long, durationMs: () -> Long, isPlaying: Boolean, onSeek: (Long) -> Unit, modifier: Modifier = Modifier, edgeInset: Dp = Dp(0f))` — the only caller is `NowPlayingScreen`. `LyricCapsule(lyricsState: LyricsUiState, positionMs: () -> Long, isPlaying: Boolean, onClick: () -> Unit)` (private to NowPlayingScreen.kt).

- [ ] **Step 1: WavyProgressBar takes providers**

Change the two parameters:

```kotlin

    durationMs: Long,
```

to:

```kotlin
    /** Read here, not by the caller, so a playback tick recomposes this bar and not the screen around it. */
    positionMs: () -> Long,
    durationMs: () -> Long,
```

and replace:

```kotlin

    val playedFraction = dragFraction
        ?: (positionMs.toFloat() / safeDuration.toFloat()).coerceIn(0f, 1f)
```

with:

```kotlin

```

- [ ] **Step 2: LyricCapsule takes a provider**

In NowPlayingScreen.kt change:

```kotlin
private fun LyricCapsule(lyricsState: LyricsUiState, positionMs: Long, isPlaying: Boolean, onClick: () -> Unit) {

```

to:

```kotlin
private fun LyricCapsule(lyricsState: LyricsUiState, positionMs: () -> Long, isPlaying: Boolean, onClick: () -> Unit) {
```

(the rest of the function keeps using the local `positionMs: Long`).

- [ ] **Step 1: Remember the pages**

Replace:

```kotlin
    val pages = AuraDestination.topLevelRoutes
    PagedContainer(
        state = motion,
        pages = pages.map { destination ->
            @Composable {
                when (destination) {
                    AuraDestination.Home ->
                        HomeScreen(navController = navController, playerViewModel = playerViewModel)
                    AuraDestination.Library ->
```
